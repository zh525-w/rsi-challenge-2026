# 实验记录：A/B/C 三数据集各 10 轮离线续训（v2.8 定稿：tune12/13 再扫描，B/C 双双刷新）

- 运行方式：提交镜像 `rsi-cpu-abc:2.8` 容器内（Python 3.10.11 alpine / numpy 1.26.4 / BLAS 4 线程）与云主机（Python 3.12.11 / numpy 1.26.4 / 2 核）双环境，由本地宿主替身按 `contest.harness.workspace.v2` 协议驱动固定入口 `python3 /app/harness.py train`（SDK contest_harness 1.0.4，产物走 chunked-v1 分块上传）；候选测量用公开验证集独立复算；预测走 `python3 /app/harness.py predict` 行协议。
- 轮数与平台一致：每数据集 10 轮；每轮一次真实决策调用（本地替身可回放静态配方，或经 `--trio-base/--trio-weights` 真实调用 PyTRiO 微调模型），调用号计入 `finish.model_call_ids`。
- 续训合规：官方 `contest.cpu-mlp.v1` 检查点，继承权重/Adam 矩/累计 steps·epochs/标准化与目标缩放；每轮起点链均为「官方 baseline 父检查点 → 逐轮择优」；未改网络结构、输入维度与类别。

## 训练机制版本线

1. v2.2：余弦学习率 + 类别均衡 + 验证最优 epoch 快照（epoch≤80，单候选）。
2. v2.3：5% warmup、EMA(0.999) 权重与矩平均（每 epoch 原始/EMA 取验证更优者）、epoch 上限 600、每轮 3 候选对照。
3. v2.4：机制同 v2.3 + 决策提示注入经验配方（RECIPE_HINTS）。
4. v2.5：每轮 4 候选——主配置 + lr×0.6/ep×1.6 + lr×1.6/ep×0.6 + 正则变体（分类标签平滑 0.05 / 回归输入噪声 0.01），后三者种子偏移 101/202/303；SWA（验证 top-3 epoch 快照的权重与矩平均）参与每候选竞争；决策 JSON 白名单新增 `label_smoothing`(0-0.2)、`input_noise`(0-0.1)。
5. v2.6：机制同 v2.5；tune8 确认 A/B 饱和（当时），C 链更新为 tune8d 混合阶梯。
6. v2.7：tune9/10/11 整链重排扫描，三链全部刷新（A 0.743865 / B 619.327 / C 50.5390）。
7. **v2.8（本版）**：训练机制不变；tune12/13 再扫 11 条链，**B 热开局再进一步（0.005/10/128/0.1 → 617.480）、C 收尾再加深（r9 104ep → 50.5299）**；A 维持 0.743865（a6/a7 复核饱和）。镜像标签 2.8。

## tune14 结构探测（v2.8 定稿后复核，2026-11-23 深夜，5 链全部无增益）

邻域饱和之后，tune14 补测了仅剩的**结构维度**缺口，结论：v2.8 三链全部维持。

1. **b12（B，SGDR 循环热梯）**：从基线起 10 个短热循环（0.005/6 起，lr 逐轮微降至 0.0035/12）。r1 采纳（681.160→619.589），其后 9 个循环全部回滚（621.59~621.73）→ **循环重启在 B 上不累积增益**，链终值 621.588。
2. **b13（B，热开局 + 长阶段二）**：r1 = 0.005/10/128/0.1 第 4 次逐位复现 617.4801615391623；r2-r10 为 9 个结构不同的长低 lr 打磨轮（30~120ep、lr 0.0005~0.002），**全部回滚**，最接近 r9 0.0009/90/256/0.02→617.868（+0.388）。至此 B 在邻域（70+ 组）与结构（循环/长阶段二）两个维度均确认饱和。
3. **a8（A，热开局重排）**：r1 = 0.006/20/128/0.1 热开局（采纳，0.714030→0.729539）后接 a4 主链。热开局把轨迹带偏：a4 原本的 r1-r3（.003/60、.002/120、.001/200）在新状态下全部回滚，链终值 0.740439 < 0.743865 → **A 的 .003/60 开局不可替换**，与 a7 的“in 不得先于 ls”共同说明 A 链顺序强敏感。
4. **c12（C，链中热重启）**：c8 前 8 轮逐位复现，r9 = 0.002/30/256/0.1 重启循环**被采纳**（50.593244→50.564030，增益 0.0292），但重启后的状态打磨性显著变差：r10（c8 同款 0.0009/96/256/0.03）仅增益 0.0128（c8 中为 0.0419），链终值 50.551202 > 50.529883 → 重启有局部收益、无全局收益。
5. **c13（C，主配置输入噪声）**：c8 前 7 轮逐位复现，r8 加 input_noise=0.02 直接变差（50.6076→50.6335，回滚），后续沿 c8 r9/r10 收尾至 50.570642 → **C 对主配置噪声有害**（与 A 的 in0.03 收官相反，数据集特性不同）。

tune14 合计新增 5 条链、约 40 组新配置探测，全部回滚确认 v2.8 定稿值：**A 0.7438654616966273 / B 617.4801615391623 / C 50.529883277739**。三链自本版起在邻域与结构两个维度均无已知改进方向，调优收敛。

## tune15 候选级复盘与穷尽扫描（2026-11-24 凌晨，4 链全部无增益，调优终结）

tune15 先从多候选对照日志复盘了三个定稿值的**真实获胜候选**，再针对暴露的最后一块未扫空间做穷尽探测：

- **复盘发现**：①B 的 617.4801615391623 获胜者是 trial4（主配置 0.005/10/128/0.1 + noise 0.01 + seed_offset 303），主配置 seed0 本身只到 634.33——此前 70+ 组探测全部是主配置 seed0 空间，显式噪声空间未扫过；②A 的 0.7438654616966273 获胜者是 trial3（派生 lr×1.6/ep×0.6 = 0.0064/27/96/0.1 + noise），且 Macro-F1 为离散网格值，解释了 in0.03/0.04“逐位一致”实为落入同一混淆矩阵（a4r7 与 a7r8 四候选得分逐项相同）；③C 的 r9/r10 获胜者均为主配置 trial1，C 确实收敛于主配置空间。
- **b15（B，显式噪声空间 9 探测）**：r1 锚点第 5 次逐位复现 617.4801615391623；r2-r10 以显式 input_noise(0.01/0.015/0.02) 主配置扫 lr 0.004-0.008 × bs 96-160 × end 0.0-0.1，**全部回滚**（最接近 0.005/10/160/0.1+in0.01→619.203）。617.48 为该噪声/种子组合的特异最优点。
- **a9（A，获胜单元显式化 + balanced 开关）**：r1-r7 逐位复现 a4 链至 0.743865462；r8 获胜单元 0.0064/27/96/0.1+in0.03 显式主配置（含 3 个新派生）、r9 0.006/30/128+in0.03、r10 balanced=false 变体，**全部回滚**。A 收官于离散网格点 0.7438654616966273。
- **c14/c15（C，压缩最弱轮 + 第三收尾）**：将 c8 增益最小的 r8（0.0009/88/256/0.03，+0.0144）挤出，改为 r8=104ep、r9=96ep 双收尾提前 + r10 第三收尾（c14 插值 0.00085/100/224/0.025、c15 重复 104ep）。两链均 10/10 采纳但终值 c14=50.546765、c15=50.547184，**均差于 c8**：压缩后第三收尾增益缩至 0.0071-0.0235，补不回被挤掉的 0.0144。

tune15 合计 4 链 22 组新探测全部回滚。至此三条链在**邻域、结构、噪声/种子、候选显式化**四个维度均已穷尽（B 累计 80+ 组回滚、A 累计 20+ 组、C 家族 10 个变体），**v2.8 即最终定稿：A 0.7438654616966273 / B 617.4801615391623 / C 50.529883277739**，离线调优终结。
