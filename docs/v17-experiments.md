## 资源效率

v17 每个数据集只做 3 次探针，其余轮次冻结；冻结轮保留一次 `max_tokens=2` 的模型调用。预计 Token 与运行时长明显低于 v15 的十轮全训练，最终以平台试运行报告为准。
