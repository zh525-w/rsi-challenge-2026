## 提交物

- 镜像：`rsi-a-cpu-1.0-alpine.tar`，122,501,120 B（116.8 MiB），sha256 `0eeee06618140d113367c1a7c6bc6b3e356cdb568b6445d59ffd54350a5321ef`
- 决策模型：`Qwen/Qwen3.8-27B`，每轮由 SDK `rnd.model()` 调用（30 轮约 17,413 token）；预测器为 NumPy 续训，CPU 运行
- 源码：`contest_submission.py`（32,498 B）+ `rsi/core.py`（11,419 B）

## 方法（v14）

- **数据集 A**：在基线模型上迭代续训，按公开验证集均分是否回退决定采纳。
- **数据集 B**：同一采纳规则，按 RMSE 判断。
- **数据集 C**：沿用父模型特征路径，缺失通道仅在覆盖度 ≥ 50% 时填 0；2 epoch、lr 5e-4、每轮换种子（42 + 轮次）、不做锚定；按 `meta.source_subset` 切 FD001–FD004 四段，容差 0，任一阶段回退则整轮不采纳。
- **Token 控制**：提示词只保留数据集、轮次、指标、父分；历史从 5 轮压到 2 轮，输出上限 96 → 48。
