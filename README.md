## 方法概要

- 链式续训：每轮继承父检查点权重 / Adam 矩 / 累计步数与标准化参数，候选在公开验证集上不优于父模型即回滚
- 每轮 4 候选对照：主配置 + lr×0.6/ep×1.6 + lr×1.6/ep×0.6 + 正则变体（分类标签平滑 / 回归输入噪声），种子偏移 101/202/303
- 训练器：5% warmup + 余弦学习率、EMA(0.999) 权重与矩平均、验证 top-3 epoch 快照 SWA 平均
- 每轮恰好一次真实驱动模型调用（平台网关，≤27B）给出本轮超参 JSON，提示注入离线经验配方 RECIPE_HINTS；可选 PyTRiO LoRA 微调 4B 决策模型
- 未改网络结构、输入维度、类别与检查点格式，符合续训约束
